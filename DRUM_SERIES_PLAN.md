# Drum Lesson Series — Project Plan

Format per episode: **one ~5-minute episode + three YouTube Shorts** (1080×1920, ~20 s, loop-back endings).

## Planned episodes, in order

1. How to hold drumsticks (and common mistakes) — ✅ LIVE on YouTube
2. The drum kit explained: what each piece does — ✅ LIVE on YouTube
3. Your first rock beat in 5 minutes — ✅ LIVE on YouTube (Short 3 still to make: needs ElevenLabs credits)
4. How to read drum music: the staff, where each drum lives, and reading your first beat — 🔄 CURRENT
   (kept as "reading music" because Episode 3's outro and description promise it; built around the rock beat viewers already play;
   no note-value names yet: beams/pairs are shown as "1 &", the names come in Episode 6)
5. Add more to your beat: simple rock-beat variations (play first, then see each one in notation)
6. Quarter, eighth, and half notes: counting rhythm (creator: introduce note values only after viewers have played them)
7. Your first drum fill
8. Time signatures made simple
9. Rests: the silence that makes the groove
10. Playing your first full song pattern

Work only on the current episode; don't start later episodes until asked.

## Style established in Episode 1

- Bright blue background with rays, red drum mascot (lip-synced to narration), Fredoka font.
- Word-by-word karaoke captions (active word yellow, key words pink).
- Real footage/photos of the creator's own hands in framed "REAL LIFE" cards; AI images tagged "CLOSE-UP". **No drawn hands.**
- Logos: leave as-is on the creator's own photos/video and AI images; blur only on third-party stock photos.
- Workflow: script + audio → stills → low-res preview → final render (4K for episodes, 1080×1920 for Shorts).
- Deliver to the creator via GitHub links (phone can't save files from the chat).
- **All series files live in this repo (`Didinegron/Drum-Series-`)**: one `episode-NN/` folder per episode, code in `tools/`. Files over 100 MB (4K masters) stay off GitHub.
